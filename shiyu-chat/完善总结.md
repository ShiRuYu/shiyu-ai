**CoT 流程：**
1. 理解问题 - 明确题目要求
2. 分析条件 - 列出已知信息
3. 逐步推导 - 一步步推理（核心）
4. 得出结论 - 总结最终答案

#### 1.4 思维树组件 (ChatToTCmp) ✅
- ✅ 实现了完整的 ToT 决策流程
- ✅ 多方案生成（默认 5 个候选）
- ✅ 自动评估打分机制
- ✅ 最优方案选择和精细化

**ToT 流程：**
1. 发散阶段 - 生成多个候选方案
2. 评估阶段 - 对每个方案打分
3. 收敛阶段 - 选择最优方案
4. 精细化 - 基于最优方案生成最终答案

## 技术亮点

### 1. 双层匹配策略
```
用户输入 → 关键词匹配（快速）→ 失败 → 大模型匹配（精准）
```
- 提高响应速度
- 保证识别准确率
- 降低成本

### 2. 渐进式对话策略
根据问题复杂度自动选择对话模式：
- 简单问题 → Direct（快速响应）
- 中等问题 → CoT（结构化推理）
- 复杂问题 → ToT（多角度分析）

### 3. 配置化架构
- 意图定义与代码分离
- 支持热更新配置
- 易于业务扩展

### 4. 容错设计
- 所有组件设置 `isContinueOnError=true`
- 多层降级策略
- 完整的错误日志

## 扩展指南

### 添加新的对话模式

1. **创建新的 LiteFlow 组件**
```java
@LiteflowComponent("CHAT_REACT")
public class ChatReActCmp extends NodeComponent {
    @Override
    public void process() {
        // 实现 ReAct 模式
    }
}
```

2. **在 chain.json 中添加链**
```json
{
  "name": "chatReAct",
  "value": "THEN(CHAT_REACT)"
}
```

3. **在配置文件中添加意图**
```yaml
- id: "react_search"
  name: "搜索查询"
  type: "REACT"
  content: "需要搜索外部信息的问题"
  keywords: ["搜索", "查询"]
  chain-to-call: "chatReAct"
```

### 自定义提示词

在对应的 Cmp 类中修改 `buildPrompt` 方法：
```java
private String buildCotPrompt(String query) {
    // 自定义 CoT 提示词
    return "你的定制化提示词";
}
```

## 性能优化建议

1. **缓存热点意图**
   - 对常见问题的意图识别结果进行缓存
   - 减少重复的大模型调用

2. **异步处理**
   - ToT 的方案生成可以并行化
   - 使用 CompletableFuture 优化

3. **批量评估**
   - ToT 的评分阶段可以批量处理
   - 减少 API 调用次数
