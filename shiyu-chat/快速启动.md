# 快速启动指南

## 前置条件

1. **JDK 21+**
2. **Maven 3.6+**
3. **API Key** - 需要配置大模型的 API Key

## 配置步骤

### 1. 配置 API Key

编辑 `src/main/resources/application-ai.yml`，填入有效的 API Key：

```yaml
spring:
  ai:
    openai:
      api-key: your-siliconflow-api-key  # SiliconFlow API Key
      base-url: https://api.siliconflow.cn
      chat:
        options:
          model: deepseek-ai/DeepSeek-V3
    
    siliconflow:
      api-key: your-siliconflow-api-key
      model: THUDM/GLM-Z1-9B-0414
    
    openrouter:
      api-key: your-openrouter-api-key  # OpenRouter API Key（可选）
```

### 2. 验证配置

确保以下配置文件存在：
- ✅ `application.yml` - 基础配置
- ✅ `application-ai.yml` - AI 模型配置
- ✅ `liteflow/chain/chain.json` - LiteFlow 流程配置

### 3. 启动服务

在项目根目录执行：

```bash
cd shiyu-chat
mvn clean install
mvn spring-boot:run
```

或者在 IDEA 中直接运行 `ShiyuChatApplication.java`

### 4. 验证启动成功

看到以下日志表示启动成功：

```
Started ShiyuChatApplication in X.XXX seconds
Tomcat started on port(s): 9001 (http)
```

## 预期行为

### Direct 模式（直接对话）
- **触发关键词**: 你好、您好、hello 等
- **响应速度**: 快（1-3 秒）
- **特点**: 简洁、直接

### CoT 模式（思维链）
- **触发关键词**: 为什么、如何证明、推理等
- **响应速度**: 中等（5-10 秒）
- **特点**: 结构化、步骤清晰

### ToT 模式（思维树）
- **触发关键词**: 方案、选择、决策、对比等
- **响应速度**: 较慢（15-30 秒）
- **特点**: 多角度分析、全面

## 常见问题

### Q1: 启动时报"找不到 ModelAdapter"
**解决方案**: 检查 `application-ai.yml` 中的 API Key 是否配置正确。

### Q2: 意图识别总是返回默认值
**解决方案**: 
1. 检查意图配置文件路径是否正确
2. 确认 IntentConfig Bean 已成功加载
3. 查看日志中的意图识别过程

### Q3: CoT/ToT 模式响应很慢
**解决方案**: 
1. 检查网络连接
2. 确认 API Key 余额充足
3. 考虑使用更快的模型

### Q4: 端口 9001 被占用
**解决方案**: 修改 `application.yml` 中的端口配置：
```yaml
server:
  port: 9002  # 改为其他端口
```

## 监控和调试

### 查看日志

日志配置文件位于：`src/main/resources/log4j2.xml`

关键日志输出：
```
INTENT 节点执行完毕
开始执行 CoT（Chain of Thought）思维链推理
CoT 推理完成
开始执行 ToT（Tree of Thoughts）思维树推理
生成了 X 个候选方案
```

### 启用详细日志

在 `application.yml` 中添加：

```yaml
logging:
  level:
    com.shiyu.ai.chat: DEBUG
    com.yomahub.liteflow: DEBUG
```

### 性能监控

访问 Actuator 端点（如果启用）：
```
http://localhost:9001/actuator/metrics
```
