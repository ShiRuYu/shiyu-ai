# 对话记忆功能说明

## 功能概述

基于 LiteFlow 实现的智能对话系统，增加了完整的记忆功能，支持多轮对话上下文感知。

## 核心特性

### 1. 记忆类型

#### 短期记忆 (Short-term Memory)
- 存储最近的对话内容（用户问题和 AI 回答）
- 每个会话最多保留 10 条
- 24 小时后自动过期
- 用于维持当前会话的上下文连贯性

#### 长期记忆 (Long-term Memory)
- 从对话中提取的重要信息（用户偏好、关键事实等）
- 每个用户最多保留 50 条
- 永久保存，不过期
- 通过 AI 自动提取和评分

### 2. 对话历史
- 记录完整的对话轮次
- 每个会话最多保留 5 轮
- 包含用户输入、AI 回答、使用的模式等信息

## 工作流程

### 主流程：chatFlow
```
THEN(MEMORY_LOAD, INTENT, CHAIN_EXECUTE, MEMORY_SAVE)
```

1. **MEMORY_LOAD** - 加载记忆上下文
   - 读取短期记忆
   - 读取长期记忆
   - 读取对话历史

2. **INTENT** - 意图识别
   - 判断用户问题类型
   - 选择合适的对话模式

3. **CHAIN_EXECUTE** - 执行子链
   - chatDirect: 直接回答
   - chatCoT: 思维链推理
   - chatToT: 思维树推理

4. **MEMORY_SAVE** - 保存记忆
   - 保存对话历史
   - 添加短期记忆
   - 提取并保存长期记忆

## API 使用

### 基本对话接口

```bash
POST http://localhost:9001/chat
Content-Type: application/json

{
  "text": "你好，我叫张三",
  "sessionId": "可选，不传则自动生成",
  "userId": "user_123"
}
```

### 响应格式

```json
{
  "result": "你好，张三！很高兴认识你。",
  "intent": "{\"id\":\"direct_greeting\",\"name\":\"问候寒暄\"}",
  "chain": "chatDirect",
  "sessionId": "auto_generated_session_id"
}
```

### 多轮对话示例

#### 第一轮
```json
POST /chat
{
  "text": "我叫张三，是一名软件工程师",
  "userId": "user_zhangsan"
}
```

#### 第二轮（使用相同的 sessionId）
```json
POST /chat
{
  "text": "你还记得我是做什么的吗？",
  "sessionId": "上一轮返回的 sessionId",
  "userId": "user_zhangsan"
}
```

AI 会记住之前的对话内容，回答："你是一名软件工程师。"

## 配置参数

在 `application.yml` 中配置：

```yaml
shiyu:
  memory:
    enabled: true                    # 是否启用记忆功能
    max-short-term-memories: 10      # 短期记忆最大数量
    max-long-term-memories: 50       # 长期记忆最大数量
    max-history-records: 5           # 对话历史最大保留数
    short-term-expire-hours: 24      # 短期记忆过期时间（小时）
    auto-extract-long-term: true     # 是否自动提取长期记忆
```

## 记忆的作用

所有对话模式（Direct/CoT/ToT）都会自动使用记忆上下文：

1. **直接对话模式**：在 Prompt 中添加相关记忆和历史
2. **CoT 模式**：结合记忆进行逐步推理
3. **ToT 模式**：基于已有知识生成多角度方案

## 技术实现

### 领域模型
- `Memory`: 记忆实体
- `ConversationHistory`: 对话历史记录
- `MemoryContext`: 记忆上下文聚合

### 服务层
- `MemoryService`: 记忆管理接口
- `MemoryServiceImpl`: 基于内存的实现（可扩展到数据库）

### LiteFlow 组件
- `MemoryLoadCmp`: 加载记忆
- `MemorySaveCmp`: 保存记忆

### 控制器
- `ChatController`: 支持 sessionId 和 userId 参数

## 扩展方向

1. **持久化存储**: 将内存存储改为数据库/Redis
2. **向量检索**: 使用向量数据库实现语义记忆检索
3. **记忆整理**: 定期合并和清理记忆
4. **情感记忆**: 记录用户情感偏好
5. **知识图谱**: 构建结构化的知识网络

## 注意事项

1. 每次对话后会自动保存记忆
2. 使用相同的 sessionId 可以保持对话连贯性
3. 不同的 userId 之间的记忆是隔离的
4. 长期记忆的提取由 AI 自动完成
5. 记忆功能默认开启，可通过配置关闭
