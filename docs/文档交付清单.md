# 前后端文档交付清单

| 交付类别 | 后端产物 | 前端产物 | 验证依据 |
| --- | --- | --- | --- |
| 项目介绍 | `docs/项目介绍.md` | `docs/项目介绍.md` | 产品定位、角色、能力、边界 |
| 技术文档 | `docs/技术文档.md` | `docs/技术文档.md` | 模块、请求链、路由、状态、SSE、存储 |
| 使用文档 | `docs/使用文档.md` | `docs/使用文档.md` | 启动、配置、业务操作、排障 |
| API 契约 | `docs/参考/API接口参考.md` | OpenAPI 快照及契约脚本 | 404 路径、440 operations |
| 数据模型 | `docs/参考/领域模型与数据字典.md` | API 类型由接口参考覆盖 | 76 张 H2 基线表（含 Model 领域平台与模型表） |
| SQL 初始化 | `db/baseline/h2/schema` 与 `seed` | 不适用 | v4 schema 与 seed 仅描述空库最终状态，不包含旧基线升级或清理语句 |
| 菜单与权限 | `docs/参考/菜单角色权限矩阵.md` | `docs/参考/页面路由与角色清单.md` | 76 菜单、131 权限码、0 缺失组件 |
| 错误处理 | `docs/参考/错误码手册.md` | 页面手册常见问题 | 统一 Result、HTTP/SSE/下载差异 |
| 安全与租户 | `docs/安全与租户隔离审计.md` | 技术文档认证章节 | 过滤器、上下文、权限、租户和文件边界 |
| 部署运维 | `docs/部署运维手册.md` | `docs/部署发布与联调.md` | 构建、代理、容量、备份恢复、回滚 |
| 页面操作 | 后端菜单/权限作为事实源 | `docs/页面操作手册.md` 与截图 | 业务流程 + 76 路由逐条清单 |
| 质量联调 | `docs/质量与联调报告.md` | `pnpm run test:contract` | 静态检查、测试、构建、运行时冒烟 |
| 文档导航 | `docs/文档导航.md` | `docs/文档导航.md` | 根 README 可发现，本地链接零缺失 |

## 重新生成

```powershell
# 后端运行在 9000 时更新 API、数据字典和权限矩阵
python scripts/docs/generate_reference_docs.py

# 在 shiyu-ui 中更新 76 个页面路由清单
python scripts/docs/generate-page-route-reference.py
```

## 完整验收

```powershell
# 在 shiyu-ai 根目录执行
python scripts/docs/verify_documentation.py

# 在 shiyu-ui 根目录执行接口契约验证
pnpm run test:contract
```

验收脚本会检查所有命名文档、关键章节、Markdown 本地链接、API operation、数据库表、菜单、权限码和页面组件存在性。任何计数漂移或断链都会返回非零退出码。
