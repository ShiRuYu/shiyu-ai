# 依赖版本审计与升级记录

更新时间：2026-09-23

## 审计范围

使用 Maven Versions Plugin 检查根 POM、全部业务模块、基础设施模块和架构测试模块，并使用 Maven 依赖树确认最终解析版本。依赖升级遵循“稳定版本、实际使用、可回归验证”原则，不把里程碑、候选版或跨主版本升级混入本次变更。

## 保留版本

- Spring Boot 4.2.0-M1 的 BOM 继续统一 Spring Framework 7.1.0-M1、Spring Data 4.2.0-M1、Spring Kafka 4.2.0-M1 和 OpenTelemetry 1.64.0；本次不单独覆盖 BOM 中的观测栈版本。
- Jackson 3.2、SLF4J 2.1 alpha、Jakarta Validation 4.0 M1、Micrometer 1.18 M1、AssertJ 4.0 M1 属于预发布版本，保留当前稳定线。
- Lucene 10、MySQL Connector/J 26、LangChain4j 1.20、LangGraph4j 1.9 和 Testcontainers 2 属于跨主版本或 API 影响较大的升级，留待单独兼容性评估。
- 未被生产模块使用的规划依赖不因版本扫描结果自动升级。

## QUERY 能力核验

Spring Boot 4.2.0-M1 实际解析的 Spring Web 版本为 7.1.0-M1。对本地依赖中的 `RequestMethod` 和 `HttpMethod` 字节码检查未发现 `QUERY` 常量，因此本项目不新增 `QUERY` 映射，也不改变现有 GET/POST 路由。后续只有在依赖版本实际提供该 API 且复杂查询体确有必要时，才单独迁移接口。

## 验证要求

依赖变更后至少执行受影响模块测试、Bootstrap 测试、严格编译、架构脚本、文档检查和 `git diff --check`。版本升级成功不等同于业务行为已验证；未运行的外部数据库、对象存储和容器环境必须单独标记。
