## 核心联调断言

- 管理员登录成功；返回当前租户、角色和 access token。
- `/v1/auth/codes` 返回 131 个权限码，`/v1/system/menus/all` 返回 9 个根菜单、41 个节点。
- 知识空间查询成功。
- `/v1/auth/refresh` 使用 `{ "accessToken": "..." }` 成功返回新 token；新 token 可用，旧 token 返回业务码 401。
- localhost 前端来源预检返回 200 和对应 ACAO；未授权外部来源返回 HTTP 403。
- 匿名文件上传返回 401；上传/删除还需分别满足 `file:upload`、`file:delete`。
