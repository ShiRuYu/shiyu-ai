日期：2026-10-27。检查对象为本次提交中的后端及配套前端代码。检查包含源码、回归测试、完整构建、隔离数据库和真实浏览器流程；没有连接现有业务数据库，也没有调用收费模型。

数据库和向量 provider 在启动时选择，不支持运行中热切换。知识检索仍依赖本地 Lucene 和 manifest；本次单实例验证不能证明多副本文件一致性。配置及操作入口见 [外部基础设施切换](外部基础设施切换.md) 和 [数据库脚本说明](../scripts/database/README.md)。

## 已修复的问题

1. PostgreSQL 初始化：以事务 advisory lock 串行安装，在 READ COMMITTED 下读取最新状态并恢复原隔离级别；在增量更新前推进序列，避免固定种子 ID 与自动生成 ID 冲突。序列操作可回滚，启用教育模块但缺失教育基线时明确拒绝启动。
2. PostgreSQL SQL 拆分：正确处理含 `$` 的标识符、Unicode dollar tag、带 `_e` 后缀的标识符与转义字符串边界。
3. JDBC：删除固定 PostgreSQL 密码回退；元数据探测失败直接报错，避免把不可用数据库误缓存为 H2 方言。
4. pgvector：统一余弦分数及阈值为 `(1 + cosine) / 2`；维度谓词匹配部分索引，EXACT 使用精确排序，ANN 过滤候选不足时精确补查。事务内迭代扫描设置不会污染连接池；并发初始化使用 advisory lock。1–2000 维支持 HNSW，2001–16000 维保留原始精度并精确检索。
5. PostgreSQL 业务写入：配额插入只请求生成的 ID；知识索引激活显式绑定可空任务 ID，并使用跨数据库数值转换；AGENT_VERSION 删除标志与整数逻辑删除模型对齐，补齐 H2/PostgreSQL 自动更新及 PostgreSQL/MySQL 手工升级脚本。
6. 令牌消费：兼容 JSON 将永久有效期 Long.MAX_VALUE 序列化为字符串；回归覆盖归属、过期、会话清理和条件更新竞争。
7. 前端：忽略切换空间、重置或退出后的过期异步响应；成员未加载或加载失败时禁止保存，防止把原成员权限替换为空集合。
8. 门禁与证据：补充真实 JDBC 事务、回滚、租约、取消传输和恢复等回归；修复严格编译警告、缺失的中文接口/类型说明及租户索引归属校验。历史功能注释基线与领域覆盖率阈值未放宽。
9. 浏览器 Agent 测试：按当前订阅阶段协议验证 HTTP 200 SSE FAILED、持久化消息 ID、刷新及原输入重试；不再把异步执行失败固定断言为 HTTP 409。
10. 内置控制台测试依赖 Vitest 从 4.1.11 升至 4.1.12，配套前端从 4.1.9 升至 4.1.12，修复受影响的 @vitest/mocker 依赖。历史 OSV 门禁报告的公告为 [GHSA-qxg6-89mg-rqv8](https://github.com/vitest-dev/vitest/security/advisories/GHSA-qxg6-89mg-rqv8)、[GHSA-xp26-3454-mjgp](https://github.com/vitest-dev/vitest/security/advisories/GHSA-xp26-3454-mjgp)。未设置漏洞忽略规则。
11. 远端暴露的异步测试竞态：流的终止通知可能先于工作线程 finally 清理；两个流式恢复用例改为有界等待清理调用，保留终态、失败事件和禁止调用同步执行器的断言。严格编译下恢复测试 17 项通过，见 `agent-async-cleanup-release.log`。
