#### InMemoryGraphStore（无外部依赖）

```java
@Component
public class InMemoryGraphStore implements GraphStore {

    // 节点表
    private final Map<Long, Knowledge> nodes = new ConcurrentHashMap<>();

    // 邻接表：child → parents
    private final Map<Long, Set<Long>> parentMap = new ConcurrentHashMap<>();

    // 邻接表：parent → children
    private final Map<Long, Set<Long>> childMap = new ConcurrentHashMap<>();

    @Override
    public List<Long> findMissingPrerequisites(Long targetId, Set<Long> masteredIds) {
        List<Long> all = topologicalSort(targetId);
        return all.stream()
                .filter(id -> !masteredIds.contains(id))
                .filter(id -> !id.equals(targetId))
                .toList();
    }

    @Override
    public List<Long> topologicalSort(Long rootId) {
        List<Long> result = new ArrayList<>();
        Set<Long> visited = new HashSet<>();
        visit(rootId, visited, result);
        Collections.reverse(result);
        return result;
    }

    private void visit(Long id, Set<Long> visited, List<Long> result) {
        if (visited.contains(id)) return;
        visited.add(id);
        for (Long parentId : parents(id)) {
            visit(parentId, visited, result);
        }
        result.add(id);
    }
}
```

#### AbilityValue

```java
public record AbilityValue(
        Long studentId,
        Long knowledgeId,
        double remember,
        double understand,
        double apply,
        double analyze,
        double evaluate,
        double create,
        LocalDateTime lastUpdated
) {
    public double overallScore() {
        return (remember * 0.15
                + understand * 0.20
                + apply * 0.25
                + analyze * 0.20
                + evaluate * 0.10
                + create * 0.10);
    }
}
```

#### EbbinghausCurve

```java
public class EbbinghausCurve {

    public static final int[] INTERVALS_DAYS = {1, 3, 7, 15, 30, 90};

    public static double mastery(Instant lastStudyAt, int reviewRound) {
        double lambda = 0.20 / (1 + reviewRound * 0.3);   // 复习轮次越高，衰减越慢
        long days = Duration.between(lastStudyAt, Instant.now()).toDays();
        return Math.exp(-lambda * days);
    }

    public static List<LocalDate> scheduleReviewDates(LocalDate learnedAt) {
        return Arrays.stream(INTERVALS_DAYS)
                .mapToObj(learnedAt::plusDays)
                .toList();
    }
}
```

## 4. 与已有 AI 能力的对接

### 4.1 教育 Agent（TeacherAgent 示例）

新建在 `shiyu-ai-agent/src/main/java/com/shiyu/ai/aiagent/education/`：

```java
@Component
public class TeacherAgent {

    private final ChatEngine chatEngine;                    // 来自 shiyu-ai-core
    private final KnowledgeService knowledgeService;        // 来自 shiyu-ai-knowledge
    private final AbilityService abilityService;            // 来自 shiyu-ai-knowledge

    public String teach(Long studentId, Long knowledgeId) {
        // 1. 查知识点及前置关系
        Knowledge k = knowledgeService.getById(knowledgeId);
        List<Knowledge> prereqs = knowledgeService.getPrerequisites(knowledgeId);

        // 2. 查学生当前能力值
        AbilityValue ability = abilityService.get(studentId, knowledgeId);

        // 3. 组装 prompt
        String prompt = buildTeachPrompt(k, prereqs, ability);

        // 4. 调用 LLM
        ChatResponse resp = chatEngine.chat(ChatRequest.builder()
                .prompt(prompt)
                .build());

        return resp.getContent();
    }
}
```

### 4.2 智能出题 Agent（PracticeAgent）

```java
@Component
public class PracticeAgent {

    private final ChatEngine chatEngine;
    private final QuestionService questionService;
    private final AbilityService abilityService;

    public List<Question> generate(Long studentId, Long knowledgeId, int count) {
        AbilityValue ability = abilityService.get(studentId, knowledgeId);
        DifficultyLevel difficulty = mapDifficulty(ability.overallScore());

        String prompt = buildPracticePrompt(knowledgeId, difficulty, count);
        ChatResponse resp = chatEngine.chat(ChatRequest.builder().prompt(prompt).build());

        List<Question> questions = parseQuestions(resp.getContent());
        questionService.saveBatch(questions);
        return questions;
    }

    private DifficultyLevel mapDifficulty(double score) {
        if (score < 40) return DifficultyLevel.BASIC;
        if (score < 70) return DifficultyLevel.MEDIUM;
        if (score < 90) return DifficultyLevel.HARD;
        return DifficultyLevel.COMPETITION;
    }
}
```

### 4.3 LangGraph4j 教育图

复用现有 `Graph` + `BaseNode`：

```java
@Component
public class TutorGraphBuilder {

    private final TeacherAgent teacherAgent;
    private final PracticeAgent practiceAgent;
    private final ExamAgent examAgent;

    public Graph buildTutorGraph(Long studentId, Long knowledgeId) {
        Graph g = new Graph();

        g.addNode("plan", new PlanNode(knowledgeId));
        g.addNode("teach", new TeacherNode(teacherAgent, studentId));
        g.addNode("practice", new PracticeNode(practiceAgent, studentId));
        g.addNode("review", new ReviewNode());

        g.addEdge("plan", "teach");
        g.addEdge("teach", "practice");
        g.addConditionalEdge("practice", result -> {
            Double score = (Double) result.get("score");
            return score < 60.0 ? "teach" : "review";
        });

        return g;
    }
}
```

```
LiteFlow learningChain:
    1. checkKnowledgeCmp   → 检查前置缺失 (KnowledgeGraph)
    2. loadResourceCmp     → 加载讲义/视频 (shiyu-ai-education)
    3. teacherCmp          → TeacherAgent 调用 LLM (shiyu-ai-core)
    4. practiceCmp         → PracticeAgent 出题 (shiyu-ai-education + shiyu-ai-core)
    5. scoreCmp            → 评分
    6. updateMasteryCmp    → AbilityService 更新能力值
                            ReviewScheduler 安排复习
```
