## 常见故障速查

| 报错 | 原因 | 修复 |
|------|------|------|
| `Cycle detected` | Maven 循环依赖 | 检查 pom.xml，确保 shiyu-ai-model 不依赖其他模块 |
| `package xxx does not exist` | import 未改 | 检查 6.1 批量替换表 |
| `Invalid bound statement` | Mapper XML 路径不对 | `application.yml` mapper-locations 加 `classpath*:**/*.xml` |
| `Bean 'xxx' not found` | @ComponentScan 漏包 | `ShiyuAgentApplication` 扫描包加上新模块包前缀 |
| `Flyway migration failed` | SQL 语法错误 | 检查 H2 vs MySQL 语法差异（H2 不支持某些 MySQL 关键字） |
| `LangGraph4j node not found` | 节点类型未注册 | 检查 `NodeFactory` 是否扫描到新模块的 `@Component` |
| `Sa-Token token invalid` | 登录后 token 未传 | 用 `curl -H "Authorization: Bearer <token>"` 或在 Swagger UI 中设置 |
