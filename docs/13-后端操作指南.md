## 第一章：环境搭建与启动

### 1.1 环境要求

| 工具 | 版本 | 检查命令 |
|------|------|---------|
| JDK | ≥ 21（推荐 Eclipse Temurin 21 LTS） | `java -version` |
| Maven | ≥ 3.9 | `mvn -version` |

### 1.2 构建项目

```bash
git clone <repo-url>
cd shiyu-ai
mvn clean install -DskipTests
```

构建成功标志：`BUILD SUCCESS`

> 首次构建约 1-3 分钟，如失败先检查 JDK 和 Maven 版本。

### 1.3 启动项目

```bash
cd shiyu-ai-bootstrap
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

启动成功日志：
```
Started ShiyuBootstrapApplication in 8.456 seconds
数据库初始化完成
```

### 1.4 验证服务

```bash
# 验证服务是否正常
curl -s http://localhost:9000/actuator/health
# 返回: {"status":"UP"}

# 访问 API 文档
open http://localhost:9000/doc.html
```

### 1.5 服务端口

默认端口：**9000**，可在 `application.yml` 中修改：

```yaml
server:
  port: 9000
```

## 第二章：登录认证

### 2.1 默认账号

| 用户名 | 密码 | 角色 |
|--------|------|------|
| vben | admin123 | super（超级管理员） |
| admin | admin123 | admin（管理员） |
| jack | admin123 | user（普通用户） |

### 2.2 登录获取 Token

```bash
curl -s -X POST 'http://localhost:9000/auth/login' \
  -H 'Content-Type: application/json' \
  -d '{"username":"vben","password":"admin123"}'
```

**返回示例：**

```json
{
  "code": 200,
  "data": {
    "accessToken": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
  }
}
```

### 2.3 设置 Token 变量

后续所有 API 调用都需要 Token：

```bash
TOKEN="a1b2c3d4-e5f6-7890-abcd-ef1234567890"
```

> VS Code REST Client 用户可直接打开 `docs/http/00-认证中心.http`，执行登录后 Token 自动保存到环境变量。

### 2.4 验证 Token

```bash
curl -s 'http://localhost:9000/auth/check' \
  -H "Authorization: Bearer $TOKEN"
```

### 2.5 获取用户信息

```bash
curl -s 'http://localhost:9000/auth/user-info' \
  -H "Authorization: Bearer $TOKEN"
```

### 2.6 获取当前用户菜单

```bash
curl -s 'http://localhost:9000/menu/all' \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```

> 该接口返回当前角色可见的所有菜单树，前端根据此数据渲染左侧导航。

## 第十章：配置文件详解

### 10.1 主配置 `application.yml`

```yaml
server:
  port: 9000                  # 服务端口

sa-token:
  timeout: 7200               # Token 有效期（秒），2 小时
  token-prefix: Bearer        # Token 前缀
```

### 10.2 AI 配置 `application-ai.yml`

```yaml
shiyu:
  ai:
    platforms:
      deepseek:
        api-key: ${DEEPSEEK_API_KEY:}        # 从环境变量读取
        base-url: https://api.deepseek.com
      siliconflow:
        api-key: ${SILICONFLOW_API_KEY:}
        base-url: https://api.siliconflow.cn
```

> 设置环境变量方式：
> ```bash
> export DEEPSEEK_API_KEY=sk-your-key-here
> ```

### 10.3 数据库配置 `application-h2.yml`

```yaml
mybatis-flex:
  datasource:
    agent:
      url: jdbc:h2:file:${app.home}/data/h2/agentdb;MODE=MySQL
      username: sa
      password:
```

## 第十一章：切换数据库（H2 → MySQL）

### 11.1 创建 MySQL 数据库

```sql
CREATE DATABASE shiyu_ai CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

### 11.2 添加 MySQL 配置

新建 `application-mysql.yml`：

```yaml
mybatis-flex:
  datasource:
    agent:
      type: druid
      driverClassName: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://localhost:3306/shiyu_ai?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
      username: root
      password: your_password
```

### 11.3 激活 MySQL Profile

```bash
# 方式一：命令行
mvn spring-boot:run -Dspring-boot.run.profiles=dev,mysql

# 方式二：修改 application.yml
spring:
  profiles:
    active: dev,mysql
```

### 11.4 首次初始化

首次连接空 MySQL 数据库时，`DatabaseInitializer` 会自动建表并插入种子数据。

> MySQL 方式更适合生产环境，H2 仅用于开发调试。

## 第十二章：常见问题 FAQ

### Q1: 启动报端口被占用

```bash
lsof -i :9000          # 查看占用
kill -9 <PID>          # 释放端口
# 或修改 application.yml 中的 server.port
```

### Q2: H2 数据库损坏

```bash
# 删除数据文件，重启自动重建
rm -rf ~/shiyu-ai/data/h2/
```

### Q3: Maven 构建失败

```bash
# 清理后重试
mvn clean install -DskipTests -U

# 或删除本地仓库后重试
rm -rf ~/.m2/repository/com/shiyu
```

### Q4: 登录返回 401 未授权

**原因：** Token 过期或 Header 格式不正确。

**解决：**
```bash
# 重新登录获取新 Token
curl -s -X POST 'http://localhost:9000/auth/login' \
  -H 'Content-Type: application/json' \
  -d '{"username":"vben","password":"admin123"}'

# 确认请求头格式
curl -s 'http://localhost:9000/auth/check' \
  -H "Authorization: Bearer $TOKEN"   # 注意有 Bearer 前缀和空格
```

### Q5: 菜单数据为空

**原因：** 数据库初始化未正确执行。

**解决：** 检查数据库中的 menu 表：

```sql
-- 进入 H2 Console 查看
SELECT id, name, parent_id, `order` FROM menu ORDER BY id;
-- 应有 id=1500~1507 的教育中心数据
```

### Q6: AI 功能返回密钥错误

```bash
# 检查环境变量是否设置
echo $DEEPSEEK_API_KEY

# 或直接在 application-ai.yml 中写入 key（不推荐提交到 git）
```

### Q7: API 响应跨域错误

**前端开发环境：** 无需配置，Vite 自动代理。
**生产环境：** 后端配置 CORS：
```yaml
shiyu:
  cors:
    allowed-origins: http://your-frontend-domain.com
```
