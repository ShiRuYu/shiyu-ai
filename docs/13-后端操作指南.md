## 二、启动项目

### 2.1 构建

```bash
cd shiyu-ai
mvn clean install -DskipTests
```

首次构建约 1-3 分钟，成功日志最后几行：

```
[INFO] BUILD SUCCESS
[INFO] ------------------------------------------------------------------------
[INFO] Total time:  01:23.456s
```

> `-DskipTests` 跳过测试加速构建，如需测试则去掉此参数。

### 2.2 启动

**方式一：Maven 直接启动（推荐开发用）**

```bash
cd shiyu-ai-bootstrap
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

**方式二：IDEA 启动**

1. 打开 `shiyu-ai` 项目
2. 找到 `ShiyuBootstrapApplication.java`
3. 右键 → Run，VM Options 添加：`-Dspring.profiles.active=dev`
4. 或直接设置 Active Profiles 为 `dev`

**方式三：jar 包启动**

```bash
cd shiyu-ai-bootstrap/target
java -jar shiyu-ai-bootstrap.jar --spring.profiles.active=dev
```

### 2.3 验证启动成功

启动日志最后出现：

```
Started ShiyuBootstrapApplication in 8.456 seconds
数据库初始化完成
```

### 2.4 访问地址

| 服务 | 地址 |
|------|------|
| API 文档 | http://localhost:9000/doc.html |
| H2 控制台 | http://localhost:9000/h2-console |
| OpenAPI | http://localhost:9000/v3/api-docs |

## 三、模块说明

```
shiyu-ai/
├── shiyu-ai-bootstrap/    ← 启动模块，聚合所有依赖
├── shiyu-ai-core/         ← 核心公共代码（常量/工具/异常码）
├── shiyu-ai-dal/          ← 数据访问层（DDL + seed data + DatabaseInitializer）
├── shiyu-ai-auth/         ← 认证授权（登录/菜单/角色/用户管理 API）
├── shiyu-ai-agent/        ← AI Agent 引擎（LangGraph4j 图编排）
├── shiyu-ai-model/        ← AI 模型适配层
├── shiyu-ai-knowledge/    ← 知识引擎（知识图谱 DAG + RAG）
├── shiyu-ai-education/    ← 教育业务域（学科/课程/题库/考试/学习/复习）
├── shiyu-ai-record/       ← 日常记录（人物/时间线）
├── shiyu-ai-memory/       ← AI 记忆与对话管理
├── shiyu-ai-mcp/          ← MCP 协议集成
├── shiyu-ai-rag/          ← RAG 检索增强生成
└── shiyu-ai-workflow/     ← LiteFlow 聊天工作流
```

### 模块间依赖关系

```
bootstrap
  ├── auth (菜单/角色/用户)
  ├── education (学科/课程/题库/考试/学习/复习)
  │     ├── knowledge (知识图谱)
  │     └── agent (AI Agent)
  ├── record (人物/时间线)
  ├── memory (对话/记忆)
  ├── mcp (MCP 工具)
  ├── model (AI 模型)
  ├── rag (RAG)
  └── workflow (工作流)
```

所有模块依赖 `shiyu-ai-core`（公共核心）和 `shiyu-ai-dal`（数据访问）。

## 四、数据库说明

### 4.1 当前数据库

默认使用 **H2 文件数据库**，数据持久化到本地文件：

```yaml
url: jdbc:h2:file:${app.home}/data/h2/agentdb;MODE=MySQL;DB_CLOSE_DELAY=-1
```

- 数据文件位置：`${app.home}/data/h2/agentdb.mv.db`
- 首次启动自动建表并插入种子数据
- 重启后数据保留（DDL 已改为 `CREATE TABLE IF NOT EXISTS`，data 已改为 `INSERT IGNORE INTO`）

### 4.2 数据库初始化流程

```
启动 → DatabaseInitializer.java (@Order(0))
  → DDL（7 个文件）：建表、索引
  → DML（9 个文件）：插入种子数据
```

| 文件 | 内容 |
|------|------|
| `01__schema_common.sql` | dict 表 |
| `02__schema_auth.sql` | tenant/user/role/menu/workspace 等 9 个表 |
| `03__schema_agent.sql` | ai_platform/ai_model/agent_def 等 5 个表 |
| `04__schema_memory.sql` | conversation_message/long_term_memory 等 3 个表 |
| `05__schema_knowledge.sql` | knowledge/knowledge_relation 等 4 个表 |
| `06__schema_education.sql` | subject/course/exam/student 等 25 个表 |
| `07__schema_record.sql` | profile/timeline_event 等 7 个表 |
| `10__data_auth.sql` | 基础权限数据 + 菜单 + 角色权限 |
| `11__data_common.sql` | 字典数据 |
| `12__data_agent.sql` | 智能体数据 |
| `13__data_record.sql` | 日常记录数据 |
| `14__data_knowledge.sql` | 知识库数据 |
| `15__data_education.sql` | 教育数据（学科/教材/课程/题目等） |
| `16__data_memory.sql` | 记忆/对话数据 |
| `17__data_menu_student_biz.sql` | 前端业务菜单（学习/练习/考试/复习/数据/AI助手） |
| `18__data_menu_edu_center.sql` | 教育中心菜单（1500~1507）+ 角色权限 |

### 4.3 查看 H2 数据库内容

1. 浏览器访问 http://localhost:9000/h2-console
2. 连接配置：
   - JDBC URL: `jdbc:h2:file:${app.home}/data/h2/agentdb;MODE=MySQL`
   - User Name: `sa`
   - Password: 留空

## 六、API 调试

### 6.1 使用 Swagger

访问 http://localhost:9000/doc.html 查看所有 API。

### 6.2 使用 VS Code REST Client

项目已内置 `.http` 文件，位于 `docs/http/`：

```bash
docs/http/
├── 00-认证中心.http         # 登录/登出/Token
├── 01-Agent引擎.http        # Agent CRUD + 执行 + Graph
├── 02-知识图谱.http         # 知识点/图谱/搜索
├── 03-教育业务域.http       # 学科/教材/课程/题目/考试
├── 04-教育Agent.http        # AI 讲解/出题/组卷/复习
├── 05-AI对话与模型.http     # Chat/平台/模型管理
├── 06-用户与权限管理.http   # 用户/角色/菜单/租户
└── 07-人物记录与人脉.http   # Profile/记录/时间线
```

使用方式：

1. VS Code 安装 **REST Client** 插件
2. 打开 `00-认证中心.http`，先执行登录请求
3. 登录后会获取 Token（自动保存到环境变量）
4. 再打开其他 `.http` 文件调用业务接口

### 6.3 curl 示例

```bash
# 1. 登录获取 Token
curl -s -X POST 'http://localhost:9000/auth/login' \
  -H 'Content-Type: application/json' \
  -d '{"username":"vben","password":"admin123"}' | python3 -m json.tool

# 返回值示例：
# {
#   "code": 200,
#   "data": {
#     "accessToken": "xxxx-xxxx-xxxx"
#   }
# }

# 2. 使用 Token 调用业务接口
TOKEN="xxxx-xxxx-xxxx"
curl -s 'http://localhost:9000/menu/all' \
  -H "Authorization: Bearer $TOKEN" | python3 -m json.tool
```

## 七、配置文件详解

### 7.1 主配置 `application.yml`

```yaml
server:
  port: 9000                # 服务端口

shiyu:
  upload:
    path: ${app.home}/data/uploads  # 文件上传目录

sa-token:
  timeout: 7200             # Token 有效期（秒）
  token-prefix: Bearer      # Token 前缀
```

### 7.2 开发环境 `application-dev.yml`

由 Maven profile `dev` 激活（默认），包含：
- AI 平台配置（OpenAI / DeepSeek / 硅基流动 等）
- H2 内存/文件数据库

### 7.3 H2 配置 `application-h2.yml`

```yaml
mybatis-flex:
  datasource:
    agent:
      driverClassName: org.h2.Driver
      url: jdbc:h2:file:${app.home}/data/h2/agentdb;MODE=MySQL;...
```

### 7.4 AI 配置 `application-ai.yml`

AI 平台 API Key 配置：

```yaml
shiyu:
  ai:
    platforms:
      deepseek:
        api-key: ${DEEPSEEK_API_KEY:}
        base-url: https://api.deepseek.com
      siliconflow:
        api-key: ${SILICONFLOW_API_KEY:}
        base-url: https://api.siliconflow.cn
```

> API Key 优先从环境变量读取，未设置时使用默认空值（部分功能不可用）。

### 7.5 MCP 配置 `application-mcp.yml`

MCP 服务器配置，用于 AI Agent 工具调用。

## 八、从 H2 切换到 MySQL

### 8.1 添加 MySQL 依赖

在 `shiyu-ai-dal/pom.xml` 中添加：

```xml
<dependency>
    <groupId>com.mysql</groupId>
    <artifactId>mysql-connector-j</artifactId>
</dependency>
```

### 8.2 创建 MySQL 数据源配置

新建 `application-mysql.yml`：

```yaml
spring:
  datasource:
    agent:
      type: druid
      driverClassName: com.mysql.cj.jdbc.Driver
      url: jdbc:mysql://localhost:3306/shiyu_ai?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
      username: root
      password: your_password
```

### 8.3 激活 MySQL Profile

```bash
# 方式一：命令行参数
mvn spring-boot:run -Dspring-boot.run.profiles=dev,mysql

# 方式二：修改 application.yml 中的 profiles.active
spring:
  profiles:
    active: dev,mysql
```

### 8.4 首次初始化

首次连接空数据库时，项目会自动执行 DDL 建表和 data 插入种子数据（`DatabaseInitializer` 自动检测并执行）。

## 九、常见问题

### Q1: 启动报 `Address already in use`

**原因：** 端口 9000 已被占用。

**解决：**

```bash
# 查看端口占用
lsof -i :9000

# 修改端口：application.yml 中 server.port 改为其他端口
# 前端 .env.development 中 VITE_GLOB_API_URL 也要同步修改
```

### Q2: H2 数据库文件损坏

```bash
# 删除数据文件，重启后自动重建
rm -rf ${app.home}/data/h2/
```

### Q3: 登录返回 `用户已被禁用`

**原因：** H2 数据库重建后用户 data 重新插入。

**解决：** 重新启动即可，数据已持久化不会重复丢失。

### Q4: Maven 构建失败

```bash
# 清理缓存重新构建
mvn clean install -DskipTests

# 如果还是失败，删除本地仓库缓存
rm -rf ~/.m2/repository/com/shiyu
```

### Q5: Swagger 文档打不开

**原因：** 访问地址不对或服务未启动。

**解决：**

```bash
# 确认服务状态
curl -s http://localhost:9000/actuator/health

# 直接访问
open http://localhost:9000/doc.html
```

### Q6: API 返回 401

**原因：** Token 过期或未携带。

**解决：** 重新登录获取新 Token，确保请求头包含 `Authorization: Bearer xxx`。

### Q7: 菜单数据不正确

**原因：** 数据库迁移文件未正确执行，18 号文件可能缺失。

**解决：** 查看 `menu` 表中是否有 id=1500~1507 的记录。若无，手动执行 `18__data_menu_edu_center.sql` 中的 SQL。
