# 接口规范

## 1. 通用规范

### 1.1 基本约定

| 项       | 规范                                           |
| -------- | ---------------------------------------------- |
| 协议     | HTTPS                                          |
| 格式     | JSON                                           |
| 编码     | UTF-8                                          |
| 时间格式 | ISO 8601 (yyyy-MM-dd'T'HH:mm:ss)               |
| 分页     | page (从 1 开始)、size (默认 20，最大 100)     |
| 认证     | Bearer Token (JWT)                             |
| 版本     | /api/v1/                                       |

### 1.2 统一响应

```json
{
  "code": 200,
  "message": "success",
  "data": { ... }
}
```

### 1.3 分页响应

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "list": [ ... ],
    "page": 1,
    "size": 20,
    "total": 100,
    "pages": 5
  }
}
```

### 1.4 错误码

| code  | 说明             |
| ----- | ---------------- |
| 200   | 成功             |
| 400   | 参数错误         |
| 401   | 未登录           |
| 403   | 无权限           |
| 404   | 资源不存在       |
| 500   | 服务器内部错误   |
| 1001  | 用户已存在       |
| 1002  | 密码错误         |
| 2001  | 知识点不存在     |
| 2002  | 课程不存在       |
| 3001  | AI 服务不可用    |
| 3002  | 模型不存在       |

## 11. 管理后台接口

### 11.1 知识点管理

```http
POST   /api/v1/admin/knowledge          新增
PUT    /api/v1/admin/knowledge/{id}     修改
DELETE /api/v1/admin/knowledge/{id}     删除
GET    /api/v1/admin/knowledge/{id}     详情
```

### 11.2 题库管理

```http
POST   /api/v1/admin/question           新增
PUT    /api/v1/admin/question/{id}      修改
DELETE /api/v1/admin/question/{id}      删除
POST   /api/v1/admin/question/batch     批量导入
```

### 11.3 教材管理

```http
POST   /api/v1/admin/textbook           新增
PUT    /api/v1/admin/textbook/{id}      修改
DELETE /api/v1/admin/textbook/{id}      删除
```

### 11.4 用户管理

```http
GET    /api/v1/admin/user               列表
POST   /api/v1/admin/user               新增
PUT    /api/v1/admin/user/{id}          修改
DELETE /api/v1/admin/user/{id}          删除
PUT    /api/v1/admin/user/{id}/status   启用/禁用
```

### 11.5 数据导出

```http
GET /api/v1/admin/export/students?grade=9

```
