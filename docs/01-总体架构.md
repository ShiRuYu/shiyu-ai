### 3.1 学习流程调用链

```mermaid
sequenceDiagram
    participant S as 学生
    participant LC as LearningController
    participant LS as LearningService
    participant LE as LearningEngine
    participant KE as KnowledgeEngine
    participant AI as AIService
    participant DB as MySQL

    S->>LC: 请求学习"绝对值"
    LC->>LS: startLearning(studentId, knowledgeId)
    LS->>KE: getKnowledge(绝对值)
    KE-->>LS: Knowledge + Relations
    LS->>LE: plan(knowledge, ability)
    LE->>KE: getLearningPath(绝对值)
    KE-->>LE: [整数, 自然数, 数轴, 绝对值]
    LE-->>LS: LearningPlan
    LS->>AI: teach(knowledge, student)
    AI->>AI: SearchKnowledge
    AI->>AI: LLM.chat()
    AI-->>LS: 讲解内容
    LS->>AI: practice(knowledge)
    AI-->>LS: 练习题
    LS->>DB: updateProgress(studentId, mastery)
    LS-->>S: 学习结果
```

### 3.2 AI Tutor 调用链

```mermaid
sequenceDiagram
    participant S as 学生
    participant TA as TeacherAgent
    participant PA as PracticeAgent
    participant EA as ExamAgent
    participant RA as ReviewAgent
    participant PA2 as PlannerAgent

    S->>TA: 我要学习导数
    TA->>PA2: plan(导数)
    PA2->>PA2: KnowledgeGraph.DFS(导数)
    PA2-->>TA: [函数, 一次函数, 二次函数, 极限, 导数]
    TA->>TA: teach(函数基础)
    TA-->>S: 讲解内容
    S->>PA: 开始练习
    PA->>PA: generateQuestions(函数)
    PA-->>S: 练习题
    S->>EA: 模拟考试
    EA->>EA: generateExam([函数..导数])
    EA-->>S: 试卷
    S->>RA: 安排复习
    RA->>RA: scheduleReview(ebbinghaus)
    RA-->>S: 复习计划
```

## 4. 部署架构

### 4.1 单机部署

```
+----------------------------+
|      Spring Boot 4         |
|                            |
|  shiyu-ai.jar              |
|                            |
|  +-- HTTP API              |
|  +-- AI Service            |
|  +-- Learning Engine       |
|  +-- Knowledge Engine      |
|  +-- RogueMap              |
|  +-- SQLite (dev)          |
|  +-- File Storage          |
+----------------------------+
```

部署命令：

```bash
java -jar shiyu-ai.jar
```

无需：Redis、Neo4j、Elasticsearch、Milvus、Kafka、RabbitMQ、MinIO

### 4.2 Docker 部署

```yaml
version: "3.8"
services:
  shiyu-ai:
    image: shiyu/ai-platform:latest
    ports:
      - "8080:8080"
    volumes:
      - ./data:/app/data
      - ./resources:/app/resources
    environment:
      - SPRING_PROFILES_ACTIVE=prod
      - DB_URL=jdbc:mysql://mysql:3306/shiyu
    depends_on:
      - mysql

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: root
      MYSQL_DATABASE: shiyu
    volumes:
      - mysql_data:/var/lib/mysql

volumes:
  mysql_data:
```

## 5. DDD 分层

```
Domain Layer
+-- Entity          领域实体 (Knowledge, Course, Question, Student)
+-- Value Object    值对象 (Mastery, Ability, Difficulty)
+-- Repository      仓储接口
+-- Domain Service  领域服务 (LearningEngine, KnowledgeEngine)
+-- Event           领域事件 (LearnCompleteEvent, ExamSubmitEvent)

Application Layer
+-- Application Service  应用服务 (LearningService, ExamService)
+-- DTO                  数据传输对象
+-- Assembler            DTO <-> Entity 转换
+-- Command/Query        CQRS 命令/查询

Infrastructure Layer
+-- Repository Impl      仓储实现
+-- RogueMap Impl        RogueMap 存储实现
+-- MySQL Impl           MyBatis-Flex 实现
+-- AI Client            Spring AI 客户端
+-- MCP Client           MCP 工具调用

Interface Layer
+-- Controller           REST API
+-- WebSocket Handler    实时推送
+-- SSE Handler          流式输出
```

## 6. 插件化设计

教育域通过接口与平台解耦：

```java
public interface BusinessDomain {
    String domain();
    void register(AbstractApplicationContext ctx);
    List<AbstractAgent> agents();
    List<McpTool> tools();
    List<LiteFlowChain> chains();
}
```

```java
@Component
public class EducationDomain implements BusinessDomain {

    @Override
    public String domain() {
        return "education";
    }

    @Override
    public List<AbstractAgent> agents() {
        return List.of(
            teacherAgent,
            practiceAgent,
            examAgent,
            reviewAgent,
            plannerAgent,
            reportAgent
        );
    }
}
```
