## 2. 模块架构（当前）

```
shiyu-ai (根 pom)
│
├── Platform Layer
│   ├── shiyu-ai-bootstrap    启动入口 (Spring Boot Application)
│   ├── shiyu-ai-auth         认证授权 (Sa-Token RBAC + 多租户)
│   ├── shiyu-ai-dal          数据访问层 (DO/Mapper/多数据源)
│   ├── shiyu-ai-record       学习记录 (Profile/Media/Tag/Timeline)
│   └── shiyu-common          公共基础 (core/excel/mybatis/thread/web)
│
├── AI Core Layer
│   ├── shiyu-ai-model        跨模块共用模型 (BO/VO/Enum)
│   ├── shiyu-ai-core         ChatEngine + ModelAdapter (5 平台)
│   ├── shiyu-ai-agent        Agent 引擎 (LangGraph4j + 19 种 Node)
│   ├── shiyu-ai-memory       记忆服务 (短期/长期)
│   ├── shiyu-ai-rag          RAG 检索增强
│   └── shiyu-ai-mcp          MCP 工具扩展
│
├── Knowledge Engine
│   ├── shiyu-ai-knowledge    知识图谱 (DAG + RogueMap)
│   │   ├── GraphStore        图存储接口 + RogueMap 实现
│   │   ├── LearningPath      学习路径算法 (DFS/BFS/拓扑排序)
│   │   ├── Ability           能力模型 (Bloom Taxonomy)
│   │   └── Review            遗忘曲线 (Ebbinghaus)
│
└── Business Domain
    └── shiyu-ai-education    K12 教育业务域 (92文件)
```

## 3. 调用链

### 3.1 AI Chat 调用链

```
用户请求 → Sa-Token 鉴权 → UserContextInterceptor
    → Controller (Auth/Menu/Agent...)
    → Service (AgentService/AgentAdminService...)
    → Repository (UserRepository/AgentAdminRepository...)
    → Mapper (UserMapper/AgentDefMapper...)
    → DataSource (H2/MySQL)
```

### 3.2 Agent 执行调用链

```
AgentService.execute(agentId, input)
    → AgentDefinition.getGraph()
    → StateGraphBuilder.build()
    → Graph.execute(input)
        → NodeFactory.createNode(NodeConfig)
        → for each node in topological order:
            → BaseNode.apply(state)
                → LLM: ChatEngine.chat/stream
                → RAG: RagService.retrieve
                → Memory: MemoryService.save/retrieve
                → Tool: ToolService.execute
                → Intent: IntentDefinitionFactory.lookup
                → Condition: ConditionNode.evaluate
    → AgentState output
```

### 3.3 知识图谱调用链

```
KnowledgeController
    → KnowledgeService
        → GraphStore (RogueMapGraphStore)
            → RogueMap DB (./data/knowledge-graph.db)
        → KnowledgeMapper (MySQL)
```

## 4. 认证鉴权流程

```
请求 → SaServletFilter
    ├── 排除路径 (/auth/login, /auth/captcha, /doc.html...)
    │   └── 放行
    └── 需鉴权路径
        ├── SaTokenDaoImpl.get(token)
        │   ├── Caffeine 缓存命中 → 返回 loginId
        │   └── 缓存未命中 → UserDO.extInfo 读取 → 验证过期 → 返回 loginId
        ├── UserContextInterceptor.preHandle()
        │   ├── SaTokenHelper.getLoginUserFromSession()
        │   │   ├── session 缓存命中 → LoginContextHolder.setContext()
        │   │   └── session 未命中 → 从 DB 加载 → saveLoginUserToSession()
        │   └── LoginContextHolder.setContext(loginUser)
        └── Controller 处理
```

## 5. DB 初始化流程

```
DatabaseInitializer.run()
    → auth 数据源: auth__init.sql (租户/用户/角色/菜单/工作空间)
    → agent 数据源: agent__init.sql (AI 平台/模型), memory__init.sql (消息/记忆/执行记录)
    → common 数据源: common__init.sql (字典)
    → record 数据源: record__init.sql (人物/记录/标签/时间轴)
```
