# Roadmap

## 1. 概述

项目分三个阶段演进，兼顾可落地性与长期扩展：

```
V1 (MVP)     → 核心功能可上手，快速上线
V2 (Smart)   → 知识图谱 + 智能推荐 + AI Tutor
V3 (AI)      → 多Agent + 数字教师 + 长期记忆
```

## 2. V1 - MVP 阶段

### 目标

搭建完整的基础数据体系，能跑通最基本的"学习-练习-考试"闭环。

### 核心功能

```
[1] 知识点体系
    +-- 学段 / 学科 / 教材版本
    +-- 章节 / 知识点 录入
    +-- 知识点列表 / 搜索

[2] 教材映射
    +-- 教材版本管理
    +-- 教材-章节-知识点 关联

[3] 课程
    +-- 课程创建 / 章节管理
    +-- 课程-知识点关联
    +-- 课程列表 / 详情

[4] 题库
    +-- 题目录入 (选择/填空/解答)
    +-- 题目-知识点关联
    +-- 题目难度分级
    +-- 按知识点筛选题目

[5] 学习记录
    +-- 学生学习某知识点记录
    +-- 做题记录
    +-- 基础掌握度 (0~100)

[6] 考试
    +-- 手动组卷
    +-- 在线考试
    +-- 提交/评分

[7] AI 聊天
    +-- 基础 Chat 对接
    +-- 对话历史 (Memory)
    +-- SSE 流式输出

[8] 用户系统
    +-- 注册/登录/JWT
    +-- 学生/教师/管理员
    +-- 基础 RBAC

[9] 学习计划 (基础)
    +-- 手动创建计划
    +-- 按日期安排任务
```

### 技术交付

| 模块                 | 内容                                         |
| -------------------- | -------------------------------------------- |
| 后端                 | Spring Boot 4 + MyBatis-Flex + MySQL         |
| AI                   | Spring AI 对接 1~2 个 Provider               |
| 前端 (管理)          | 题库/课程/用户增删改查                       |
| 前端 (学生)          | 课程浏览/做题/考试/对话                      |
| 数据                 | MySQL 建表 + 导入基础知识点 (~500)           |

### 预计周期

- 后端: 4~6 周
- 前端: 4~6 周
- 数据: 2 周 (并行)

## 3. V2 - Smart 阶段

### 目标

引入知识图谱、能力模型、智能推荐、遗忘复习，从"能用"升级为"好用"。

### 核心功能

```
[1] 知识图谱
    +-- 知识点关系 (PRE/NEXT/SIMILAR/RELATED)
    +-- GraphStore (RogueMap 实现)
    +-- DFS/BFS/拓扑排序
    +-- 知识点可视化图谱

[2] 能力模型
    +-- Bloom Taxonomy 六维度
    +-- 能力值跟踪 (每次做题/考试后更新)
    +-- 能力雷达图

[3] 学习路径
    +-- 智能学习路径生成
    +-- 缺失前置知识检测
    +-- 路径可视化

[4] 智能出题
    +-- AI 生成题目 (LLM)
    +-- 按知识点 + 难度自动出题
    +-- 自适应难度

[5] 错题本
    +-- 自动收录错题
    +-- 错题复习
    +-- 相似题推荐

[6] 艾宾浩斯复习
    +-- 自动生成复习任务 (1/3/7/15/30/90天)
    +-- 智能复习推荐
    +-- 遗忘曲线模型

[7] 推荐系统
    +-- 知识点推荐 (补前置)
    +-- 题目推荐 (薄弱点专练)
    +-- 资源推荐 (Embedding 语义匹配)

[8] 学习分析
    +-- 学习时长统计
    +-- 掌握度趋势
    +-- 薄弱点分析
    +-- 进步曲线

[9] LiteFlow 工作流
    +-- 学习流程编排
    +-- 复习流程
    +-- 考试流程

[10] RAG
     +-- 教材文档解析
     +-- 知识库检索
     +-- 增强 AI 回答

[11] Embedding
     +-- 知识点向量化
     +-- 语义搜索
     +-- TopK 相似查询
```

### 技术交付

| 模块         | 内容                                               |
| ------------ | -------------------------------------------------- |
| RogueMap     | 知识图谱/Embedding/缓存/推荐索引/AI Memory         |
| LiteFlow     | 学习/复习/考试 流程编排                            |
| RAG          | 文档加载 + 切分 + 检索 + 生成                      |
| 前端 (知识图谱) | ECharts/D3.js 可视化                              |

### 预计周期

- 后端: 6~8 周
- 前端: 4~6 周
- 数据: 持续完善知识点关系 (目标 15000+)

## 4. V3 - AI 阶段

### 目标

构建完整的 AI Tutor 多 Agent 系统，实现个性化教学、自动课程规划、智能出题、学习诊断和长期学习记忆。

### 核心功能

```
[1] AI Tutor 多 Agent
    +-- TeacherAgent   (讲解)
    +-- PracticeAgent  (出题)
    +-- ExamAgent      (组卷)
    +-- ReviewAgent    (复习)
    +-- PlannerAgent   (规划)
    +-- ReportAgent    (分析报告)
    +-- CoachAgent     (学习教练)

[2] LangGraph4j
    +-- 复杂Agent状态机图
    +-- Planner -> Knowledge -> Teacher -> Practice -> Review
    +-- 条件分支 + 循环

[3] 长期记忆
    +-- 学生学习画像
    +-- 学习偏好
    +-- 个性化 Agent 响应

[4] MCP 工具
    +-- OCR (图片识别)
    +-- TTS (文字转语音)
    +-- ASR (语音转文字)
    +-- 搜索知识点/题目
    +-- 生成PPT / 课程大纲

[5] 数字教师
    +-- 拟人化教师 Agent
    +-- 个性化教学风格
    +-- 多轮对话教学
    +-- 实时答疑

[6] 自适应学习
    +-- 实时能力评估
    +-- 动态调整学习路径
    +-- A/B 测试不同教学策略

[7] 成长档案
    +-- 学习成就系统
    +-- 周/月度报告
    +-- 家长端可视化

[8] 知识森林
    +-- 跨学科知识关联
    +-- 综合题/项目式学习
    +-- 知识迁移

[9] 多模态学习
    +-- 图片题目
    +-- 视频讲解分析
    +-- 手写识别
```

### 技术交付

| 模块               | 内容                                           |
| ------------------ | ---------------------------------------------- |
| LangGraph4j        | Multi-Agent 状态机图                           |
| MCP                | 工具注册 + LLM 调用                            |
| Long-term Memory   | 学生画像 + 个性化 Agent                        |
| 数字教师           | 多模态 + 多轮 + 个性化                         |

### 预计周期

- 后端: 8~12 周
- 前端: 6~8 周
- AI 调优: 持续

## 5. 技术基础持续优化

贯穿三个阶段：

```
[1] 性能
    +-- 接口响应 < 200ms
    +-- RogueMap 读写优化
    +-- 缓存命中率 > 80%

[2] 安全
    +-- 数据加密
    +-- 接口限流
    +-- 审计日志

[3] 可观测性
    +-- 日志聚合
    +-- 链路追踪
    +-- 性能监控

[4] 部署
    +-- Docker 镜像
    +-- Kubernetes (生产)
    +-- CI/CD

[5] 文档
    +-- API 文档 (OpenAPI)
    +-- 架构设计文档
    +-- 开发规范
```
