## 2. 构建顺序

```
shiyu-common (BOM → core → mybatis → excel → thread → web)
      ↓
shiyu-ai-model (纯 POJO)
      ↓
shiyu-ai-dal (DO + Mapper + 跨模块 Repository)
      ↓
shiyu-ai-core (AI 引擎)
shiyu-ai-memory (记忆服务)
shiyu-ai-rag (RAG 检索)
shiyu-ai-mcp (MCP 工具)
shiyu-ai-knowledge (知识图谱)
      ↓
shiyu-ai-agent (Agent 核心)
shiyu-ai-auth (认证授权)
shiyu-ai-record (记录管理)
      ↓
shiyu-ai-bootstrap (启动，依赖所有)
```

## 3. 依赖方向

```
shiyu-ai-model (无依赖)
     ↑
shiyu-ai-dal → 依赖 model + common-mybatis
     ↑
shiyu-ai-core → 依赖 dal + model + common-web
shiyu-ai-memory → 依赖 dal + model + common-mybatis
shiyu-ai-rag → 依赖 model + common-web
shiyu-ai-mcp → 依赖 model + common-web
shiyu-ai-knowledge → 依赖 dal + model + common-web
     ↑
shiyu-ai-agent → 依赖 core + memory + rag + mcp + dal + model
shiyu-ai-auth → 依赖 dal + model + common-web + common-core
shiyu-ai-record → 依赖 dal + model + common-web + common-core
     ↑
shiyu-ai-bootstrap → 依赖 auth + record + agent + core + dal + memory + rag + mcp + common-web + common-mybatis
```

## 4. @AutoMapper 策略

| BO 位置 | 注解位置 | 示例 |
| --- | --- | --- |
| 业务模块 (auth/agent/record) | BO 上 | `@AutoMapper(target = XxxDO.class)` |
| model 模块 (跨模块共用) | DO 上 | `@AutoMapper(target = XxxBO.class)` |

## 6. RogueMap 依赖规则

| 模块 | 依赖 | 作用 |
| --- | --- | --- |
| shiyu-ai-knowledge | `roguemap-core` | 图存储 `RogueMap<String, String>` |
| shiyu-ai-memory | `roguemap-memory` | AI 记忆 `RogueMemory` (BM25 + 向量) |

- `roguemap-memory` → 自动传递 → `roguemap-embedding`（含 `UniversalEmbeddingProvider`）
- 两个模块的 RogueMap 存储文件隔离:
  - knowledge: `./data/knowledge-graph.db`
  - memory: `./data/ai-memory`
