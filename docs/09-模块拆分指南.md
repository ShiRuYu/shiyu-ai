## 8. Mapper XML 路径

`application.yml` 或 `DataSourceConfig.java` 中的 mapper-locations 必须覆盖所有模块：

```yaml
mybatis-flex:
  mapper-locations:
    - classpath*:mapper/**/*.xml
```

当前是：
```yaml
mapper-locations: classpath*:mapper/*.xml
```

建议改为支持子目录，以适配未来 shiyu-ai-education 等模块。
