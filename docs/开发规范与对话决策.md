# ShiYu AI 开发规范与对话决策

> 本文把项目讨论中已经确认的产品边界、架构决策和交付规则固化为开发约束。代码、H2 基线、OpenAPI 和测试是行为事实源；本文用于解释为什么这样实现以及变更时必须同步什么。
>
> 关联前端规范：[shiyu-ui 开发规范与对话决策](../../shiyu-ui/docs/开发规范与对话决策.md)。

## 1. 已确认的产品方向

ShiYu AI 的定位是：**企业级 Agent/RAG 后端 + Prompt Studio + OpenAI-compatible API + 可插拔聊天前端**。SillyTavern、Dify、Open WebUI、DeepSeek Harness、MAGMA 等项目只作为公开机制的参考，不复制源码、页面或专有实现。

当前默认保持单实例、H2、本地文件、JVector 和本地任务调度。PostgreSQL/MySQL、Redis、S3/MinIO、消息队列和分布式向量存储属于后续生产化阶段，不能为了短期功能把它们偷偷引入平台核心。

## 2. 对话中形成的架构结论

### 2.1 Conversation 与 Memory 必须分离

- **Conversation** 是原始交互事实源：保存用户实际发送的消息、消息树、编辑、分支、生成和 SSE 续传事实。
- **MAGMA Memory** 是派生认知结构：保存筛选后的事件、实体和 Temporal/Semantic/Causal/Entity 关系图。
- Memory 不复制完整聊天内容；只保存提炼事件和 `sourceType/sourceId` 引用。
- Conversation 不负责长期记忆提取，Memory 不负责流式草稿、取消和生成状态。

### 2.2 Agent 平台与 Agent 执行的关系

- Agent 平台负责定义、版本、图校验、发布和权限治理。
- Agent 执行负责引用已发布版本，创建执行上下文、步骤、工具调用、模型调用和 checkpoint。
- 两者共享 `AiRun`/运行事件，但不把编辑器状态和执行状态混在同一张业务表中。
- 运行时只能调用 Published App/Agent Version；Draft 只能预览、校验或测试。

### 2.3 Prompt Studio 的边界

Prompt Studio 是模板、变量 Schema、版本、预览、对照运行和评测入口，不是意图管理页面。意图路由应归入 Agent/App 的路由配置；Prompt Studio 只消费意图结果或变量，不把意图字段塞进通用 Prompt 表。

### 2.4 Runtime 是跨模块运行事实源

一个用户请求默认只有一个根 `AiRun`。Conversation、Agent、Knowledge、MAGMA、Model、Tool 和 Evaluation 通过类型化事件写入同一运行轨迹；流式恢复使用 `(runId, seq)`，不再维护互相漂移的第二份事件正文。

### 2.5 MAGMA 是平台级记忆基座

Memory 采用独立实现的 MAGMA-based 机制：统一事件节点、四类关系图、向量/关键词/时间联合锚点、意图路由、受限图遍历、快慢双通道和带引用路径的上下文合成。它不是 MAGMA 官方实现，也不依赖 Education、Record 或具体 Agent 类型。

## 3. 后端开发规范

### 3.1 模块依赖

| 模块 | 只负责 | 禁止依赖 |
| --- | --- | --- |
| Conversation | 原始会话、消息树、GenerationRun、SSE | Education、Record、长期 Memory |
| Runtime | AiRun、运行事件、Trace、usage、审批 | 具体业务实体和供应商请求类型 |
| MAGMA Memory | 事件、实体、边、索引、治理、检索 | Education、Record、Agent 具体类 |
| Agent | 图、版本、执行、checkpoint | 直接拼接供应商 prompt |
| Knowledge | 文档、切片、权限、检索 | 复制 Memory 事件表 |
| Education/Record | 领域适配器和授权 | 修改平台通用表结构来承载领域字段 |

### 3.2 API 与数据契约

1. 新接口使用按领域组织的 `/api/{domain}/**` 路径；不恢复旧版本化路径、旧 `/chat/**`、旧 `MemoryService` 或旧 memory 数据兼容层。
2. 模型输入必须是结构化消息和 content parts；平台层禁止把消息降级成单字符串 prompt。
3. 普通写请求使用 `Idempotency-Key` 和数据库唯一约束保证幂等，不能以 Controller JVM 锁替代数据库约束。
4. 客户端不能提交并信任 `tenantId`；服务端必须从认证上下文校验租户、主体、来源对象和权限。
5. 错误必须映射为稳定的 400/403/404/409/422/429/5xx 语义和项目错误码，不直接泄露 `IllegalArgumentException` 或供应商原文。
6. SSE 的 `id` 使用持久化事件 `seq`，支持 `Last-Event-ID`/`afterSeq`、心跳、终态事件和 `[DONE]`。

### 3.3 模型网关

Provider SPI 统一声明 streaming、tools、parallelTools、multimodal、jsonSchema、reasoning、contextWindow、usage 和 cancellation 能力。DeepSeek 等供应商适配器负责原生协议映射、reasoning/text 分流、usage-only frame、并行 tool calls、限流、取消、超时和 malformed frame；平台层只消费统一流事件。

供应商 Key 只能通过受控配置注入，禁止写入源码、前端、日志、Prompt Trace 或运行事件正文。缺失供应商 usage 时才使用本地估算，并明确 `estimated=true`。

### 3.4 H2 与索引

- 当前 v4 是破坏式最终基线；检测到旧基线时拒绝启动，部署方备份后人工重建，程序不迁移或删除旧数据。
- H2、JVector、关键词索引和 consolidation job 必须能从正式数据重建。
- 运行数据、构建产物、截图、测试报告和本地密钥不提交到 Git。
- 服务启动时必须遵守数据目录锁，禁止多个进程写同一个 H2/JVector 目录。

## 4. 前端全局交互规范

以下规则通过 `@vben/styles/naive` 全局生效，新增页面不得局部覆盖成相反行为：

### 4.1 下拉菜单和完整文本

- 下拉菜单按内容伸展，不默认强制等于触发控件宽度。
- 菜单最大宽度受视口约束；移动端不得产生页面级横向滚动。
- 选择器的选中值保留完整 `title`，鼠标悬浮可以查看全文。
- 选项标签不能因为固定宽度而截断；确需截断时必须提供可访问的完整文本。
- 该规则适用于 Chat、Agent、App Studio、Knowledge、Education、Platform Admin 等所有 Naive UI 选择器，不只修复单个页面。

### 4.2 页面壳与功能归位

- Standard：工作台、知识、列表和管理页面使用全局导航、标题行和内容工具栏。
- Immersive：Chat、学习、答题保持输入区/主要任务可见，内部滚动。
- Builder：Agent、App、Prompt 使用资源栏 + 编辑区 + 属性面板 + 测试/Trace 区。
- Focus：考试、危险确认和完整 Trace 只展示当前任务必要信息。
- 通用 Chat、Agent、RAG 进入统一 AI 控制台；教育只传入场景上下文，不复制一套聊天事实源。

### 4.3 可访问性和响应式

- 可操作目标不小于 44px；图标按钮必须有中文或英文 `aria-label`。
- 首屏必须可看到消息和输入区；Context/Trace 在移动端使用底部面板。
- 页面不得出现横向溢出、无名称按钮和未处理 Promise rejection。
- 文案进入 locale，禁止用业务页面硬编码同义标题制造重复菜单。

## 5. 变更流程与发布门禁

新增或修改一个跨模块能力时，按以下顺序执行：

1. 先更新领域边界和 API/数据契约，再改 Controller、Service、Repository 或前端页面。
2. 同步更新 OpenAPI、H2 基线/迁移、权限矩阵、前后端类型和使用文档。
3. 为正常、无权限、跨租户、并发、幂等、取消、重启恢复和移动端布局补测试。
4. 后端执行 `mvn -DskipTests=false test`；前端执行 typecheck、单测、契约检查、构建和 Playwright 关键链路。
5. 发布前确认 Prompt Preview 与真实请求 hash 一致、运行事件可按 seq 重放、上下文带来源/权限、Draft 不可执行。

推荐提交格式：

```text
docs: update development conventions
fix(ui): show complete select labels on hover
feat(conversation): persist generation events
```
