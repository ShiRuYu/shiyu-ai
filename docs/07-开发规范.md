# 开发规范

## 1. 项目结构规范

### 1.1 模块结构

```
shiyu-ai-{module}
|
+-- pom.xml
+-- src/
    +-- main/
    |   +-- java/
    |   |   +-- com/shiyu/ai/{module}/
    |   |       +-- controller/       REST Controller
    |   |       +-- service/          应用服务接口
    |   |       +-- service/impl/     应用服务实现
    |   |       +-- domain/
    |   |       |   +-- entity/       领域实体
    |   |       |   +-- valueobject/  值对象
    |   |       |   +-- repository/   仓储接口
    |   |       |   +-- event/        领域事件
    |   |       +-- infrastructure/
    |   |       |   +-- mysql/        MySQL实现 (Mapper)
    |   |       |   +-- roguesmap/    RogueMap实现
    |   |       |   +-- ai/           AI Client
    |   |       |   +-- config/       模块配置
    |   |       +-- dto/              DTO (请求/响应)
    |   |       +-- vo/               VO (视图对象)
    |   |       +-- assembler/        DTO/VO <-> Entity 转换
    |   +-- resources/
    |       +-- mapper/               MyBatis XML
    |       +-- liteflow/             LiteFlow EL 配置
    +-- test/
        +-- java/
            +-- com/shiyu/ai/{module}/
```

### 1.2 依赖原则

```
controller -> service -> domain (entity/valueobject/repository)
                      \-> infrastructure (实现 repository)
dto/vo <-> assembler <-> entity
```

- Controller 只能调用 Service，禁止直接调用 Repository
- Service 通过 Repository 接口访问数据，不感知具体实现
- Infrastructure 实现 Repository 接口（MySQL/RogueMap）

## 2. 命名规范

### 2.1 包命名

- 全小写，多个单词直接连接
- 模块名作为根包
- 例: `com.shiyu.ai.knowledge.graph`

| Service 接口      | `XxxService`         | `KnowledgeService`          |

- 全大写下划线分隔

### 3.1 Entity

使用 Record 或 immutable class (Java 21+)：

```java
@Table("knowledge")
public class Knowledge {

    private Long id;

    private String code;

    private String description;

    @Column("difficulty")
    private Integer difficulty;

    @Column("status")
    private Integer status;

    @Column("created_at")
    private LocalDateTime createdAt;

```

### 3.2 DTO

请求：

```java
public record CreateKnowledgeRequest(
    @NotBlank String code,
    @NotBlank String name,
```

## 4. Service 规范

### 4.1 接口

```java
public interface KnowledgeService {

    KnowledgeResponse getById(Long id);

    PageResult<KnowledgeResponse> page(KnowledgePageQuery query);

    KnowledgeResponse create(CreateKnowledgeRequest request);

    void update(Long id, UpdateKnowledgeRequest request);

    void delete(Long id);
}
```

### 4.2 实现

```java
@Service
@RequiredArgsConstructor
public class KnowledgeServiceImpl implements KnowledgeService {

    private final KnowledgeRepository knowledgeRepository;
    private final KnowledgeAssembler assembler;

    @Override
    public KnowledgeResponse getById(Long id) {
        Knowledge knowledge = knowledgeRepository.findById(id)
            .orElseThrow(() -> new KnowledgeNotFoundException(id));
        return assembler.toResponse(knowledge);
    }

    @Override
    public KnowledgeResponse create(CreateKnowledgeRequest request) {
        if (knowledgeRepository.existsByCode(request.code())) {
            throw new KnowledgeAlreadyExistsException(request.code());
        }
        Knowledge knowledge = assembler.toEntity(request);
        knowledgeRepository.save(knowledge);
        return assembler.toResponse(knowledge);
    }
}
```

## 5. Controller 规范

```java
@RestController
@RequestMapping("/api/v1/knowledge")
@RequiredArgsConstructor
@Tag(name = "知识点")
public class KnowledgeController {

    private final KnowledgeService knowledgeService;

    @GetMapping("/{id}")
    @Operation(summary = "获取知识点详情")
    public Result<KnowledgeResponse> getById(@PathVariable Long id) {
        return Result.ok(knowledgeService.getById(id));
    }

    @GetMapping
    @Operation(summary = "分页查询知识点")
    public Result<PageResult<KnowledgeResponse>> page(
            @Valid KnowledgePageQuery query) {
        return Result.ok(knowledgeService.page(query));
    }

    @PostMapping
    @Operation(summary = "新增知识点")
    @RequirePermission("knowledge:create")
    public Result<KnowledgeResponse> create(
            @RequestBody @Valid CreateKnowledgeRequest request) {
        return Result.ok(knowledgeService.create(request));
    }
}
```

## 6. 异常处理规范

### 6.1 业务异常基类

```java
public abstract class BusinessException extends RuntimeException {

    private final int code;

    protected BusinessException(int code, String message) {
        super(message);
        this.code = code;
    }

    public int getCode() { return code; }
}
```

### 6.2 具体异常

```java
public class KnowledgeNotFoundException extends BusinessException {
    public KnowledgeNotFoundException(Long id) {
        super(2001, "知识点不存在: " + id);
    }
}

public class KnowledgeAlreadyExistsException extends BusinessException {
    public KnowledgeAlreadyExistsException(String code) {
        super(2001, "知识点已存在: " + code);
    }
}
```

### 6.3 全局异常处理

```java
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public Result<Void> handleBusiness(BusinessException e) {
        return Result.fail(e.getCode(), e.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public Result<Void> handleValidation(MethodArgumentNotValidException e) {
        String message = e.getBindingResult().getFieldErrors().stream()
            .map(FieldError::getDefaultMessage)
            .collect(Collectors.joining(", "));
        return Result.fail(400, message);
    }

    @ExceptionHandler(Exception.class)
    public Result<Void> handleException(Exception e) {
        log.error("系统异常", e);
        return Result.fail(500, "系统异常");
    }
}
```

## 7. 统一响应

```java
public record Result<T>(int code, String message, T data) {

    public static <T> Result<T> ok(T data) {
        return new Result<>(200, "success", data);
    }

    public static Result<Void> fail(int code, String message) {
        return new Result<>(code, message, null);
    }
}
```

## 8. 分页规范

```java
public record PageResult<T>(
    List<T> list,
    long total,
    int page,
    int size
) {
    public int getPages() {
        return (int) Math.ceil((double) total / size);
    }
}
```

```java
public class PageQuery {
    @Min(1)
    private int page = 1;

    @Min(1) @Max(100)
    private int size = 20;

    public int getOffset() {
        return (page - 1) * size;
    }
}
```

## 9. 日志规范

- 使用 lombok `@Slf4j` 注解
- 入参使用 `debug` 级别
- 业务事件使用 `info` 级别
- 异常使用 `error` 级别
- 敏感信息不打印

```java
@Slf4j
@Service
public class KnowledgeServiceImpl implements KnowledgeService {

    @Override
    public KnowledgeResponse create(CreateKnowledgeRequest request) {
        log.info("创建知识点: code={}", request.code());
        try {
            Knowledge knowledge = repository.save(assembler.toEntity(request));
            return assembler.toResponse(knowledge);
        } catch (Exception e) {
            log.error("创建知识点失败: code={}", request.code(), e);
            throw e;
        }
    }
}
```

## 12. 测试规范

### 12.1 单元测试

使用 JUnit 5 + AssertJ + Mockito：

```java
class KnowledgeServiceImplTest {

    @Mock
    private KnowledgeRepository repository;

    @InjectMocks
    private KnowledgeServiceImpl service;

    @Test
    void shouldReturnKnowledgeById() {
        when(repository.findById(1L)).thenReturn(Optional.of(mockKnowledge()));

        KnowledgeResponse result = service.getById(1L);

        assertThat(result.name()).isEqualTo("绝对值");
    }

    @Test
    void shouldThrowWhenNotFound() {
        when(repository.findById(999L)).thenReturn(Optional.empty());

        assertThatThrownBy(() -> service.getById(999L))
            .isInstanceOf(KnowledgeNotFoundException.class);
    }
}
```

## 13. 分支与提交规范

### 13.1 分支

- `main`: 生产分支
- `develop`: 开发主分支
- `feature/xxx`: 功能分支
- `fix/xxx`: 修复分支
- `release/x.x.x`: 发布分支

### 13.2 Commit

```
<type>(<scope>): <subject>

feat(education): 新增知识点学习路径算法
fix(question): 修复题目难度筛选逻辑
docs(architecture): 更新总体架构文档
refactor(agent): 重构 TeacherAgent
test(knowledge): 添加知识图谱单测
```

## 14. 代码风格

- 缩进: 4 空格
- 行宽: 120 字符
- 使用 lombok 减少样板代码
- 方法长度不超过 50 行
- 类长度不超过 500 行
- 使用 `Optional` 代替 null 判断
- 使用 Stream API 简化集合操作
- 使用 record 定义 DTO/VO（Java 21+）
